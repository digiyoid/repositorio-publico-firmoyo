# Repositorio Público - Witec

Repositorio con los documentos públicos (HTML y PDF) publicados desde la web institucional de Witec.

Los documentos se organizan en carpetas por tema. El sitio se publica automáticamente vía GitHub Pages a partir de la rama `main`.

## Cómo agregar un documento nuevo
1. Colocá el archivo (PDF o HTML) en la carpeta correspondiente (o creá una nueva).
2. Actualizá `index.html` si querés que aparezca listado en la página principal.
3. Hacé commit y push a `main` — el sitio se actualiza solo en unos minutos.
